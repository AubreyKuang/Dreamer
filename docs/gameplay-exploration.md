# 浮梦之境 · Dreamer的玩法探索

玩家可以随时放手漫游。用现有航线、船灯和手记验证转向能否改变航程中的一幕。

## 第二轮　速度改变看见的东西

| ID | 玩家读取什么，再做什么 | 进展、代价与熟练策略 | 初筛 |
| --- | --- | --- | --- |
| DR-02b | 水面碎光与船速 → 停稳看倒影，或顺流看倒影展开 | 同一段水面在两种走法下出现不同构图。玩家可以重访航段试另一种。 | 已有可玩版本。[规则](features/voyage/design.md#春江花影) |
| DR-04a | 左岸花树与右岸开阔水面 → 跟一岸或过江 | 看见不同岸景，但横移占用航程。熟练玩家会在换景前选岸。 | 待测。两岸需要有独立可辨认的景物。 |
| DR-05 | 岸上先出现的光 → 向亮处转向 | 触发一段回应，但仍是接近移动目标得到分支。 | 与 DR-01a 重复。 |
| DR-06 | 诗句节奏与当前航速 → 在句间提速或慢下来 | 有意改变观看节奏。 | 待测。现有航程会在诗句节点附近限制推进，需要新的可观察后果。 |
| DR-07 | 河面和手记中的旧画面 → 选择哪张留影与眼前水面并排看 | 主动比较同一段景色在不同走法中的变化。 | 待测。得先观察玩家是否愿意回看原有手记。 |

**DR-02b 的范围。** 首个可玩版本只在「春江花月夜」的一小段水面生效。两个结果都接回原来的诗文。桌面 Chrome 的键盘和手机尺寸下的模拟触控都通过了分支检查。人工试玩仍需观察玩家能否自行理解并复现两种走法。

**两种局面。** 船刚入江湾、花影还在近处时，可以停稳看它合拢。到开阔水面时，可以顺流让银带随视角展开。如果顺流只剩普通水面，停船就变成唯一能看见变化的做法。现有代码已经按位置和时间绘制月江碎光，刹停也能与航程推进区分。[月江绘制](../js/scenery.js) · [航程推进](../js/route.js)

**最小试玩。** 同一段分别顺流和停船一次。在试玩者开口前不解释触发条件。记录他们能否说出两种速度各看见了什么，以及第二次能否主动复现。触屏、静音和减少动态效果都要保留可辨认的两种构图。人工试玩待进行。

### 航速对照

用 Chrome 的游戏循环以固定 60 Hz 推进，略过绘图来测输入与字幕的相对时刻。旧版持续加速时，银带会在结果旁白前约 8.7 秒锁定。在提示后第 16 秒才开始刹停，普通航速仍能看到花影，加速则只能看到银带。

调整后，普通速度和持续加速都会等结果旁白出现才确定银带。两种速度下，在提示后第 16 秒和第 18 秒开始刹停都可以看到花影。这里验证的是输入窗口。真人试玩还要看玩家能否自然理解提示、看清水面变化。

## 第三轮　一路跟哪一岸

| ID | 玩家读取什么，再做什么 | 进展、代价与熟练策略 | 依据与最小试玩 |
| --- | --- | --- | --- |
| DR-04b | 前方石径、浮花与当前滑行线 → 靠左、靠右或留在溪心 | 横向距离决定这一趟记住哪处景。玩家可看见两岸后换方向，也可重访。 | 从 DR-04a 的持续选岸收束到桃源一段。给玩家同一个溪口两次，第一次不讲玩法，第二次要求找到另一岸。已有可玩版本。[规则](features/voyage/design.md#桃源两岸) |
| DR-08 | 先前留影与眼前视角 → 寻找能对上旧画面的地方 | 用取景确认位置，逐步读懂环境；会花掉当前的观景时间。 | 以 DR-07 的回看为基础，加空间比对。先给一张岸景，让玩家在纸面标出两处可识别的参照。待测。 |
| DR-06a | 诗句余韵与下一句距离 → 放慢延长停留或继续滑向下一句 | 掌握观看节奏，代价是推迟下一景。 | 沿用 DR-06。若只有当前字幕停留时长变化，会与已有刹停留诗重合。要先观察读诗者是否关心下一景的来时。 |
| DR-09 | 溪水声的远近 → 蒙住景物前选一侧去找声源 | 把听声变成找路依据。需要可替代的线索才适合静音。 | 先用同一段静音和有声对照，观察声源是否改变转向时机。待测。 |

这次用同一段溪口对比了键盘左右、零输入和减少动态效果下的触屏转向。人工试玩仍需看玩家能否只靠提示和景物主动换岸，以及重访时是否愿意去另一边。

## 第四轮　从留影找到下一次走法

| ID | 玩家读取什么，再做什么 | 进展、代价与熟练策略 | 依据与最小试玩 |
| --- | --- | --- | --- |
| DR-08a | 已拍到的画面、空着的另一侧 → 保留当下取景，或重访分岔试另一种走法 | 玩家可自己决定何时拍照，并用旧图对照新图。重访占用一次短航段。 | 从 DR-08 的位置比对改为同一地点的不同走法。先留一张左岸，观察玩家能否自行重访并拍到右岸。已有可玩版本。[规则](features/voyage/design.md#两种走法的留影) |
| DR-10 | 手记中的旧照片和沿途地标 → 寻找相近的横向角度 | 对照地标找位置，可比较同一地点的不同构图。 | 纸面用一张有两处参照的照片，验证玩家能否指出该往哪边移。待测。 |
| DR-11 | 已读诗句的顺序 → 选择一次重访只追一段旁白或沿原路线读完 | 决定重访范围，代价是略过前面的景。 | 与现有航段重访相近。若玩家没有反复找同一句的需要，单独加入口价值有限。 |
| DR-12 | 两种景色尚未亲自走过 → 直接生成两张对照照片 | 照片可立即集齐。 | 淘汰。生成两张能取得同样记录，替代了实际走另一条路线。 |

真人试玩仍要看第一张留影能否让玩家产生重访动机，以及两张照片能否帮助玩家说清走法的差别。
