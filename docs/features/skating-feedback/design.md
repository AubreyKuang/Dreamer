# 滑行、刹停与落冰

**Status:** implemented · **更新** 2026-11-13 · [GDD](../../GDD.md)

通过姿势、冰屑和声音区分动作。

## 现行反馈与实测

| 动作 | 已有反馈 |
|---|---|
| 蹬冰 | 一次蹬冰声，姿态压低，冰屑随蹬力喷出。 |
| 转刃与刹停 | 人物倾身、冰屑改变，切换摩擦声。地面按住充分刹车时保留当前诗句，松开继续计时。 |
| 落冰 | 飞行状态结束时播一次转刃声，画面回落到地面滑行。 |

以 60 Hz 执行现行控制器，普通滑速刹停约 0.52 秒，持续加速的稳态速度刹停约 0.67 秒。这里测的是控制器到零速，实际浏览器掉帧与触屏输入延迟另测。[控制与渲染](../../../js/render.js) · [蹬冰](../../../js/controls.js) · [冰刀音效](../../../js/audio.js)

## 手感提案与试玩

[ASSUMPTION] 落冰优先试两层反馈：冰刀接触点的少量碎冰，配合人物约 180 ms 回稳。保留现有落地声音作为声音线索。碎冰和姿势只作用于画面，沿用减少动态效果与冰刀音效开关。测试一次落冰后立刻转向、一次快速交替蹬冰与刹停，观察是否一眼分得清三种动作，以及下一次输入是否及时生效。
