# 诗词航程与支线

**Status:** implemented · **更新** 2026-11-13 · [GDD](../../GDD.md)

沿航程读诗，自由选择在哪段停留和靠近。

## 路线和节奏

| 顺序 | 航段 | 体验 |
|---|---|---|
| 教学 | 海棠渡 → 海雾深处 → 北冥有鱼 | 开局提示先转向再刹停，鲲是第一个可预期的大景。 |
| 第一次高潮 | 天接云涛 → 天河星原 → 灯火葳蕤 | 乘风离地约 22 秒，落回冰面后给星原和林灯留观景时间。 |
| 放缓与再选择 | 蓝田 → 桃源 → 田居 → 不系之舟 | 船灯从左侧出现，可以靠过去，也可以继续顺流。两条走法在赤壁汇合。 |
| 第二次高潮与收束 | 赤壁 → 春江 → 箜篌 → 镜湖 → 寒江 | 赤壁末句另留 5 秒间隔。镜湖飞渡之后进入寒江留白。末句之后仍可滑行。 |

现有路线有 15 个航段、97 条主线诗文与旁白。转向、光点、船灯互动、自由漫游和留影都可以略过。自由漫游可返回原诗词进度，按章节跳转也可直接重访。用现行章节推进与移动逻辑，以 60 Hz、默认滑速、零输入从海棠渡跑到寒江末句，全部航段可达。该检查用替身替代了画面、声音和存储。[航段数据](../../../js/chapters.js) · [路线推进](../../../js/route.js) · [漫游切换](../../../js/main.js)

## 船灯与试玩

首次可见时，旅人船定下横向参照。贴近到内部横向差小于 18 会记为靠近。靠近时立即出现举灯回应。如果玩家在分支诗句之后才靠近，手记仍会新增相遇条目。错过可继续顺流或重访。固定步长检查里，船出现后持续向左，在默认和减少动态效果两种配置下都能在分支诗句前达到靠近条件。[船灯与分支](../../../js/route.js)

旅人船在可相遇时有额外灯光。成功靠近时灯晕短暂变亮并晃动，减少动态效果时使用静态灯晕。[旅人船绘制](../../../js/scenery.js)

[ASSUMPTION] 对同一玩家各重放一次顺流和靠近。记录是否在诗句揭晓前看出船灯从哪里来、知道向哪里转，并在离开本段后指出两种手记的不同。比较有效相遇窗口前后，看看灯光能否让玩家预判是否还来得及靠近。

## 春江花影

「花影散在水上」出现后，按住刹停并保持完全静止 2 秒，江面呈现一朵花影。若还在顺流，结果旁白出现时才会选择银带。已经按住刹停时会等玩家停稳或松手。旁白出现后，结果画面保持 3.5 秒，再用 1.8 秒淡出，沿用刹停保留诗句的计时。一趟只选择一种结果，跳回本段可重试。两个结果各自写入手记，继续上次航程时会恢复已选结果。这些时长是本轮的试玩值。[航程判定](../../../js/route.js) · [江面绘制](../../../js/scenery.js)

## 桃源两岸

「桃源深处」的提示出现时，以玩家所在位置定溪心。此后向左或向右持续转向，靠近桃树下的石径或漂着落花的浅湾。向外转向在靠近岸边时会减慢，朝溪心转仍可换岸。在「芳草鲜美，落英缤纷」出现时，横向距离达到 30 个内部世界单位就记下对应的岸景。留在溪心时继续读原诗，三种走法都接回春夜。左右岸各有一页手记，在结果旁白处续游会恢复所选岸景。减少动态效果时，两岸景物同样可见。[选岸与续游](../../../js/route.js) · [岸景绘制](../../../js/scenery.js)

## 两种走法的留影

在桃源选岸后的旁白处，或春江倒影仍清楚可见时留影，照片会带上对应走法。手记把每种走法的最新一张放在并排位置，缺的一侧会写明尚未留影。「重访分岔」从选择前开始，可以重走另一条路线。自由漫游、溪心和过了取景时机的照片仍按普通留影保存。旧照片继续可看。两类照片一起计入最近 12 张留影，原图仍按原流程下载。[画面标记](../../../js/route.js) · [留影保存](../../../js/photo.js) · [手记](../../../js/journal-ui.js)

「片段重访」直接进入江心船灯、桃源两岸或春江倒影的选择前，读到的新诗句和留影仍会存进手记。重访期间保留原航程的续游点，点「回原航程」或刷新后选择「继续上次航程」，都回到最近保存的原航程诗句。若此前没有航程，返回海棠渡开头。「重访航段」会开始一段新的主航程。[重访入口](../../../js/journal-ui.js) · [返回规则](../../../js/main.js)
