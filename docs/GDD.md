**版本** 0.1 · **更新** 2026-11-13 · [功能](#feature-index) · [设计决定](#decisions) · [更新记录](#change-log)

## 游戏概述

玩家在冰面滑行、乘风和泛舟，读沿途诗句，选择在哪里放慢、取景或留影。诗词航程结束后仍可漫游，也可以跳回某一段重新看。

- 诗词观景漫游 · 网页 · 键盘与触屏 · JavaScript / Canvas / Web Audio
- [ASSUMPTION] 目标玩家为喜欢短时观景、诗词和自由取景的玩家。

## 设计支柱

- 顺流可以读完整段航程。
- 转向、刹停和留影给玩家自己的观看节奏。
- 风景与诗句一起达到高潮，再留出安静的空白。

## 核心循环

滑入新景 → 读一句诗 → 继续、刹停或换角度 → 看见下一景或留影 → 回手记或继续航程。

## 首轮试玩

从海棠渡练习转向和刹停，留住当前诗句。关闭页面后，从最近显示的诗句续航。用手记重访「不系之舟」，比较顺流和主动向船灯靠近的体验。
