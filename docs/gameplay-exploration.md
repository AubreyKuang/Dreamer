# 浮梦之境 · Dreamer的玩法探索

玩家可以随时放手漫游。用现有航线、船灯和手记验证转向能否改变航程中的一幕。

## 已实现的试玩版本

| 试玩 ID | 玩家目标和反复选择 | 状态、进展与代价 | 依据与最小试玩 |
| --- | --- | --- | --- |
| DR-01a（DR-01；距离改变叙事而非加分） | 想回应旅人还是留在自己的航线上？读船灯的相对位置，再决定转向和速度。 | 实时驾驶 · 连续空间 · 船随航程漂开 · 近远是两种旁白和手记 · 接近只在船经过时有效，错过仍能前进。当前只在这一幕试一次。 | 源码已有移动的船灯和手记。直行保留原句，靠近才有回应。未知：手机拖动、快速滑行时，能否在船离开前读懂提示？跳到「不系之舟」，各走一遍，观察是否能有意复现两种结果。 |

人工试玩待进行。下面的判断来自源码和规则推演。

## 探索过的方向

| ID | 读取的状态 → 反复做的选择 | 进展、代价与熟练策略 | 初筛 |
| --- | --- | --- | --- |
| DR-01 | 船灯偏移、滑行速度 → 顺流或转向靠近 | 改变遇见谁 / 错过一次会合 / 预判相对位置 | 留下，改成 DR-01a |
| DR-02 | 下一段岸景与当前惯性 → 在岸边刹停或滑过去 | 多观察一个地点 / 占用航程时间 / 提前减速 | 待测；需要比现有刹停留诗多一个后果 |
| DR-03 | 光点位置、当前诗句 → 靠近光点听问候或直行 | 触发短句 / 改变滑行线 / 提前找光点 | 与现有光点机制重复 |
| DR-04 | 左右岸的景物线索 → 走一岸再换岸 | 观察两个空间不同的版本 / 错过另一岸 / 看线索换岸 | 初筛保留；要补足两岸差异 |
