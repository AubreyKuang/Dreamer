## 为 TapTap 做的改动

- **存档回退**（`js/dream-storage.js`）：手记依次试 IndexedDB → `tap.setStorageSync` → localStorage，每一种都先写入、读回一致才用；`tap` 存储按 200KB 分块，单个 key 不超过 1MB。设置和续航点要在启动时同步读出，依次试 `tap.setStorageSync` → localStorage。都不能用时照样可以玩，第一次读到诗句时提示一次「当前环境无法保存手记和航程」。
- **留影**：只有 IndexedDB 能跨次保存留影图片；退到 `tap` 或 localStorage 时，诗句照常保存，留影只保留本次游玩，并会提示。
- **TapTap 宿主**（`js/taptap.js`）：只检测全局 `tap`，不调用 `tap.login`，不联网。在 TapTap 内按「留影」不再下载 PNG（WebView 没有下载目录），照片仍收进手记。

## 定稿文案

- **游戏名：** 浮梦之境
- **副标题：** 一段有诗词相伴的冰上航程
- **一句话简介：** 跟着一朵逆风的海棠，滑过海雾、北冥与云海。
- **首页推荐语（21 字）：** 踩着冰刀滑进诗里，看海棠、看鲲、看春江花月
- **游戏类型：** 休闲
- **适龄：** 8+（古诗词旁白与风景漫游，无暴力、恐怖、付费内容）

**长简介：**

《浮梦之境》是一段有诗词相伴的冰上漫游。一朵海棠逆着风，在你的冰刀前打了个旋。你跟着它滑进海雾，隔着冰看见一条比岛还长的影子。

航程约二十一分钟，依次经过十五段风景：海棠渡、海雾深处、北冥有鱼、天接云涛、天河星原、灯火葳蕤、蓝田日暖、桃源深处、归园田居、不系之舟、赤壁赋、春江花月夜、李凭箜篌引、镜湖飞渡、寒江独钓。沿途的旁白来自古诗词和文赋：庄子的北冥之鱼，张若虚的春江月夜，柳宗元的寒江雪。读到「落英缤纷」时，桃花会从天上成片飘落。

你可以自己转向、加速，也可以随时刹停，看一会儿云。滑到云海，会随大鹏乘风而起；在不系之舟，可以靠近另一盏船灯；进了桃源，可以选左岸的石径，也可以去右边漂着落花的浅湾。读过的诗句和留影都会收进滑行手记。冰面上偶尔有一句轻声问候，可以想一想，也可以直接滑过去。

读完最后一句，冰原依然没有尽头，可以一直滑下去。

操作：左右拖动转向；上下拖动，或按住「加速」「刹停」调速；点「蹬冰」提速。「换一个梦」可以直达任意航段。单机游玩，没有内购，没有广告。

**开发者的话：**

这是我一个人做的小游戏。一开始只想做一片能一直滑下去的冰面，后来把喜欢的诗一句句放了进去：迟日江山丽，北冥有鱼，春江花月夜。这里没有分数，也没有失败，累了就按住刹停，看一会儿云。希望它能陪你安静地待上二十分钟。如果哪一段风景让你想多停一会儿，欢迎在评论区告诉我。
